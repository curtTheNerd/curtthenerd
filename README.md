# curtthenerd — Portfolio Website

Personal portfolio site built with React, TypeScript, and Vite — a dynamic, style-optional (look for "Style" in NavBar) landing page showcasing client work and side projects, plus an about/CV section and contact form.

🔗 Live: www.curtthenerd.dev

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS (including `tailwindcss-animate` / `tailwindcss-motion`)
- React Router
- `@react-spring/parallax` for the parallax-style page
- `@dnd-kit` for drag-and-drop interactions
- `react-icons`
- `react-zoom-pan-pinch` for the gallery zoom/pan
- Axios
- and more...

## Getting Started

```bash
npm install
npm run dev
```

Other scripts: `npm run build`, `npm run preview`, `npm run lint`.
